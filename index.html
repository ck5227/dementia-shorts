dementia-shorts

dementia-shorts 是 YouTube 頻道「顧好大腦」自用的上傳工具。它會把頻道自己製作的失智症衛教短片，自動上傳到頻道擁有者本人的 YouTube 頻道。

dementia-shorts is a private, single-user tool that uploads short educational videos about dementia, produced by the YouTube channel "顧好大腦", to the channel owner's own YouTube channel via the YouTube Data API.

  • 這個工具只有頻道擁有者本人使用，不開放其他使用者登入。
    Only the channel owner uses this tool; no other users sign in.
  • 只使用 youtube.upload 權限上傳影片。
    It only uses the youtube.upload scope to upload videos.
