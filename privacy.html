隱私權政策 Privacy Policy

最後更新 Last updated: 2026-11-19

1. 這個應用程式做什麼 What this app does

dementia-shorts 是 YouTube 頻道「顧好大腦」的自用工具，只用來把頻道自己製作的短片上傳到頻道擁有者本人的 YouTube 頻道。
dementia-shorts is a single-user tool used only by the owner of the YouTube channel "顧好大腦" to upload the channel's own videos to that channel.

2. 使用的 Google 資料 Google user data accessed

這個應用程式只要求 https://www.googleapis.com/auth/youtube.upload 權限，唯一用途是上傳影片和設定影片的標題、說明、標籤與公開狀態。它不讀取其他使用者的資料，也不讀取頻道的觀看者、留言或分析資料。
The app requests only the https://www.googleapis.com/auth/youtube.upload scope, used solely to upload videos and set their title, description, tags and privacy status. It does not access data of any other user, nor viewer, comment or analytics data.

3. 資料儲存與分享 Storage and sharing

OAuth 授權權杖只以加密形式存放在頻道擁有者自己的 GitHub Actions secrets 中，用來執行上傳。這個應用程式不收集、出售、或與任何第三方分享 Google 使用者資料。
The OAuth token is stored only as an encrypted secret in the channel owner's own GitHub Actions secrets and is used only to perform uploads. No Google user data is collected, sold, or shared with any third party.

4. 符合 Google 政策 Compliance

本應用程式使用 Google API 取得的資訊，遵守 Google API Services User Data Policy（包含 Limited Use 規定）。使用本應用程式即表示也適用 YouTube 服務條款 與 Google 隱私權政策。
This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of this app is also subject to the YouTube Terms of Service and the Google Privacy Policy.

5. 撤銷授權 Revoking access

可隨時在 Google 帳戶的第三方存取權頁面 撤銷本應用程式的存取權。撤銷後，GitHub 上存放的權杖會立即失效並被刪除。
Access can be revoked at any time at https://myaccount.google.com/permissions. The stored token then stops working and is deleted.
